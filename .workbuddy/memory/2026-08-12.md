# 2026-08-12

## Deep audit — follow-the-money pipeline
Static + test-run audit of `src/follow_the_money`. Suite (552 tests) is green but
masks production-path defects (no end-to-end test exercises multi-component blocks,
market-state computation, or live family grouping).

### HIGH-severity (production-path defects)
1. **Story-family / redundancy machinery dead in production.** `build_event`
   forces `story_family_id = fam_single_<event_id>` (events.py:158);
   `assign_family_ids` / `finalize_story_families` (resolution.py:115,123) are
   never called by `run_pipeline`; `distinct_first_member` (selection.py:47) is
   never set to True outside tests. So every event is its own singleton family →
   the selection redundancy penalty (scoring.md step 4) never fires, and the
   `distinct_material_development` exemption is unreachable.
2. **Market-state subsystem dead in production.** `classify_market_state`
   (state.py:82) is only used in tests; `run_pipeline` hardcodes
   `market_state` to all-"unknown" (pipeline.py:516-531). The "市场状态" section
   always shows 未判定 despite the full spec in scoring.md / architecture.md.
3. **Resolver only processes `block.components[0]`** (pipeline.py:360,366) while
   `validate_seed_coverage` demands ALL block seeds be assigned
   (resolution.py:37-66). Packed blocks normally contain multiple connected
   components (candidates.py:227 `pack_blocks`), so any multi-event feed raises
   ResolutionError (or silently drops events). Blocker for real feeds.

### MEDIUM
4. `_affected_groups` (pipeline.py:776) = `len(asset_mappings)`, counting
   `unclear`-direction mappings → Systemic Breadth overstated and marked "known"
   when only unclear mappings exist, violating scoring.md contract.
5. `_observable_z` always returns None (pipeline.py:781) → Repricing Magnitude
   permanently unknown; 20/100 significance weight unreachable in v1 (ceiling ~80).

### LOW (dead code / drift / no-ops)
6. Dead expression statement pipeline.py:491 `{a["event_id"]: a for a in analyses}`.
7. `finalize_story_families` no-op (resolution.py:118-119 discard results);
   `DimensionVote` dataclass unused (state.py:36-48).
8. `audit._collect_rendered_claims` returns inventory IDs → "outside_inventory"
   check (audit.py:65-72) is circular/no-op.
9. `scoring.family_penalty` config unused (hardcoded "15"); freshness uses
   `brief_generated_at` not `evidence_cutoff_at` (docs mismatch).
